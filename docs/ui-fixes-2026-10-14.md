# MangaReader UI and media workflow fixes — 2026-10-14

- Author sheets show only a name and expanded optional external source links. Empty links are discarded on save. Author titles use their original name, with no translation control. Existing hidden metadata is preserved when editing.
- Custom sheet headings use a consistent larger, left-aligned heading. Text fields accept focus across their bounds. The macOS Edit menu includes Cut, Undo and Redo.
- Source links have a full-width, left-aligned input without the “ID or HTTPS URL” label. New rows select an unused provider.
- Tags use a collection grid with up to three stacked comic covers and a deduplicated comic count. Edit focuses an inline name field; Return saves. The edit action becomes Delete with confirmation. Tag deletion detaches references, including hidden comics, before the existing revision-protected API deletion; comics, media and personal state survive.
- Archive destinations are added manually. Import records its source binding but never creates an archive destination. Archive moves select an existing, connected destination. Connections lists import sources separately so comics kept in place remain accessible across devices. A source can be manually enrolled as a destination.
- Direct or mounted folders and SMB connections validate `.mangareader-library.json` with library owner and destination identities. Existing mismatched/corrupt markers are rejected rather than overwritten. SMB marker creation uses AMSMB2’s exclusive creation operation. Existing source connections without a marker remain readable until explicitly enrolled.
- Delete Destination removes it from the archive list. Referenced roots remain import sources so existing comic paths and files are preserved. Unreferenced roots use the API’s soft deletion. No filesystem deletion occurs.
- Reader back controls are clickable across the whole capsule. Language and options menus use the same 44pt height and capsule shape. Phase-free horizontal wheel gestures support Magic Mouse paging; trackpad transitions and vertical image scrolling are retained.
- Smaller download buttons use a semibold arrow, pie progress, failure indicator and immediate retry. Downloads queue serially, count active/queued items in the sidebar or phone badge, support cancellation, and copy locally connected media as well as SMB media into the offline cache.
